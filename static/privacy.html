Privacy

Last updated 27 July 2026.

Tube is a small personal front end for YouTube. It is not affiliated with, sponsored by, or endorsed by YouTube or Google.

What this site collects

Nothing. There are no accounts, no analytics, no advertising, and no cookies set by this site. Search terms you type are sent to this site's server only to be forwarded to the YouTube Data API, are held in memory for at most 30 minutes so that repeating a search does not re-query YouTube, and are never written to disk. The server keeps ordinary web-server request logs, which include IP addresses, for operational purposes.

YouTube

Tube uses YouTube API Services. Search results and video playback come from YouTube. When you play something, the embedded YouTube player loads from youtube-nocookie.com, but playback still involves YouTube receiving data about that request, and YouTube may set storage in your browser once playback begins.

By using this site you are also bound by:

  • YouTube Terms of Service
  • Google Privacy Policy

You can review and revoke this site's access to your data — and see what Google holds — via the Google security settings page.

Data retention

Cached YouTube API responses expire automatically: 30 minutes for searches, 6 hours for stations, and everything is discarded when the server restarts. No YouTube API data is stored beyond that, well inside the 30-day maximum the YouTube API Services Developer Policies allow.
